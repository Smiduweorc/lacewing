# Security Policy

## Supported versions

Security and bug fixes go to the latest minor version only. They ship in the
next minor release or, if urgent, in a patch release.

Published advisories are listed in [ADVISORIES.md](./ADVISORIES.md).

## Reporting a vulnerability

Use the "Report a vulnerability" button under the Security tab of the
GitHub repository. That opens a private channel with the maintainers.
